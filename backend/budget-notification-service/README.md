# Budget & Notification Service

Manages user budgets and sends notifications.

## Responsibilities

- CRUD operations for budgets.
- Check budget status.
- Send notifications (e.g., budget alerts, anomalies).
- CRUD for notification settings.
- Provide health check and metrics endpoints.

## Running the service

```bash
npm install
npm run start:dev
```

The service will be available at `http://localhost:3004`.
